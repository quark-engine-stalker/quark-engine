## Installation

Download **`AnomalyDX11AVX.rar`** from this release's **Assets**. Extract the archive, then copy `AnomalyDX11AVX.exe` and its matching `AnomalyDX11AVX.pdb` into **`Anomaly\bin`** and confirm file replacement. Launch the game through **MO2 (Mod Organizer)**.

**Requirements:** Windows x64, an AVX2-capable processor, DX11 and Microsoft Visual C++ Redistributable x64.
